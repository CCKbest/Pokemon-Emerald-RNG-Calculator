## Download Process in any case


    1 -  Via Linux in the Terminal or using Git for Windows

        - Start by writing this command "git clone --no-checkout https://github.com/CCKbest/File-Name.git", it'll allow you to clone the repo without its content

        - Navigate via cd to the new folder "cd Folder"

        - Then write inside that folder "git sparse-checkout set File-Name/File-Name", in case of having more or less, you add or substract, and with spaces you write all in "Quotes"

        - Lastly write "git checkout" inside the folder


    2 - Via Windows

        "- git clone --filter=blob:none --sparse https://github.com/CCKbest/File-Name.git"

        Navigate onto the folder as in Bash

        "git sparse-checkout set "File-Name/File-Name", as mentioned previously with the step 3
